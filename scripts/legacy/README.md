# Legacy Scripts

These scripts are kept as a soft delete archive. They are not linked by
`./install` and should not be treated as part of the active workstation surface.

Move a script back to `scripts/` and add it to `install` only if it becomes part
of the current workflow again.

Archived here:

- `gh-clone-org` - bulk GitHub cloning helper.
- `py-setup` - older generic Python environment helper.
- `uv-setup` - older `uv` project setup helper.
- `sqlit-add-connection` - interactive SQLit connection helper.
